这是一篇**示例文章**，用于展示正文、代码和表格的阅读效果。你可以直接修改或删除它。

## 从一篇文章开始

一个小小的博客，最重要的事情是让文字有一个安稳的去处。先写下来，再慢慢整理，比搭建一个庞大的系统更容易开始。

文章放在 Markdown 文件里，页面负责排版。每一部分都很直白，也方便未来的自己接着修改。

```ts
const notes = ['保持好奇', '动手实践', '记录发现'];

for (const note of notes) {
  console.log(note);
}
```

## 给内容留出空间

- 用标题划分思路，不急着堆叠功能。
- 用代码记录可以复现的步骤。
- 用一小段总结，留住这次真正学会的东西。

> 简单不是少写几行代码，而是知道哪些事情值得认真做。

| 内容 | 存放方式 | 修改之后 |
| --- | --- | --- |
| 文章正文 | Markdown 文件 | 构建时生成文章页面 |
| 页面排版 | Astro 页面与组件 | 在本地预览中查看效果 |
| 字体与配色 | CSS 变量 | 统一调整全站样式 |

## 下一次再完善

先让这个地方有几篇想读的文章。等真正遇到需要，再添一点功能。
